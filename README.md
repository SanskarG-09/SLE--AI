# 🤖 NexaBot AI

NexaBot AI is a simple rule-based chatbot developed using Python as part of an AI-assisted learning project.

## 📌 Project Description

NexaBot AI can interact with users through the terminal and provide responses to basic inputs. The chatbot can respond to greetings, answer basic questions, tell jokes, perform simple mathematical calculations, and end the conversation when the user enters an exit command.

## ✨ Features

* 👋 Greeting responses
* 😂 Random jokes
* 💬 Basic conversation
* 🧮 Basic mathematical calculations
* 🚪 Exit command
* 🔀 Randomized responses

## ▶️ How to Run

Make sure Python is installed on your computer.

Open the project folder in VS Code and run:

```bash
python Agent.py
```

Then interact with NexaBot through the terminal.
